MONORA – Wildlands

SPIELEN:
Die Datei index.html im Browser öffnen.

AUF GITHUB PAGES VERÖFFENTLICHEN:
1. Die Datei index.html (NICHT die ZIP-Datei) in das Hauptverzeichnis des öffentlichen GitHub-Repositories hochladen.
2. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Nach der Veröffentlichung ist das Spiel über https://BENUTZERNAME.github.io/REPOSITORYNAME/ erreichbar.

Alle Spieldaten (HTML, CSS, JavaScript) sind in index.html enthalten.
Das Spiel funktioniert offline. Spielstände werden lokal im jeweiligen Browser gespeichert und sind NICHT zwischen Geräten synchronisiert.
